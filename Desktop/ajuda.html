Primeiros passos

Edite o conteúdo nas abas index.html, style.css e script.js. Clique em Executar para visualizar a página. O botão de visualização dividida permite editar e acompanhar o resultado lado a lado.

Atalhos de teclado

  • Ctrl + S — salvar projeto
  • Ctrl + F — localizar no editor
  • Ctrl + Z — desfazer
  • Ctrl + Shift + Z — refazer (pode variar conforme o sistema)
  • Ctrl + A — selecionar tudo no editor
  • Ctrl + 1 a 4 — alternar entre HTML, CSS, JavaScript e Preview

No macOS, alguns atalhos usam ⌘ em vez de Ctrl.

Gerenciar projetos

Use Salvar projeto para atualizar o projeto aberto e Salvar como para criar uma cópia com outro nome. O explorador lateral lista os projetos deste navegador e oferece ações de abrir, renomear, exportar ZIP e excluir.

Exportar ZIP gera arquivos separados para HTML, CSS e JavaScript. Faça backups regularmente.

Preview e console

O Preview executa o HTML, CSS e JavaScript do projeto em um iframe. Abaixo dele, o console mostra console.log(), console.info(), console.warn(), console.error() e erros de execução. Você pode filtrar ou limpar as mensagens.

Execute apenas códigos confiáveis. O Preview não é um ambiente de segurança para executar scripts desconhecidos.

Onde ficam meus projetos?

Atualmente, o HTMLPAD++ salva os projetos no localStorage do navegador, vinculado ao endereço do site. O indicador lateral apresenta uma estimativa do espaço ocupado pelos projetos em relação a uma referência comum de 5 MiB. Não é uma medição da cota real do navegador.

Os projetos não são sincronizados entre dispositivos. Limpar os dados do site, usar navegação privada ou trocar de navegador pode fazer você perder acesso aos projetos. Exporte ZIPs para manter cópias.

Limitações atuais e futuro

Esta versão é um editor estático: não possui banco de dados, contas de usuário nem criação de pastas reais no servidor. Uma futura versão com PHP e armazenamento em arquivos ou banco poderá permitir múltiplos arquivos, diretórios e projetos maiores.
